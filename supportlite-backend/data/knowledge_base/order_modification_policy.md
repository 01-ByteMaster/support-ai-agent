# Order Modification Policy — DEMONSTRATION DATA

Document ID: order_modification_policy
Version: 1
Effective: 2026-01-01
Applies to: All orders placed on SupportLite Store
Related documents: cancellation_policy, shipping_policy, support_procedures

## Order Modification Summary
Orders can be modified only before dispatch. Delivery address, contact number, and delivery instructions can be changed while the order is Placed or Confirmed. Product, size, colour, or quantity changes are done by cancelling the order and placing a new one.

## When an Order Can Be Modified
An order can be modified only when its status is Placed or Confirmed. Once the status is Packed, Shipped, Out for Delivery, or Delivered, modifications are not possible, because the parcel has been prepared or handed to the courier.

## Changing the Delivery Address
- Address changes are allowed once per order, before dispatch.
- The new address must be in a serviceable pin code. If it is not, the change is rejected.
- If the new address changes the shipping fee, the difference must be paid before the change is applied.
- After dispatch, the address cannot be changed. The customer may contact the courier directly using the tracking number, but a change is not guaranteed.

## Changing the Phone Number or Email
Contact details can be updated before dispatch by contacting support with the order ID. For security, the request must be made from the registered email address or verified through an OTP sent to the registered phone number.

## Changing Product, Size, Colour, or Quantity
Items in a placed order cannot be edited directly. To change them:
1. Cancel the order following the cancellation_policy while it is still before dispatch.
2. Place a new order with the correct items.
Prices, discounts, and stock availability at the time of the new order apply and may differ from the original.

## Adding Items to an Existing Order
Items cannot be added to an existing order. A separate order must be placed. Shipping charges apply to each order separately.

## Changing the Payment Method
The payment method cannot be changed after an order is placed. Customers who want to switch, for example from Cash on Delivery to prepaid, must cancel and reorder.

## Coupons and Discounts
A coupon cannot be added or removed after an order is placed. Coupons are not applied retroactively.

## Gift Messages and Invoice Details
Gift messages and GST / billing details can be updated before dispatch by contacting support. After dispatch, a corrected invoice can be issued on request but the parcel is not changed.

## Delivery Date and Slot Changes
Delivery dates are estimates. Requests to schedule delivery for a specific date can be passed to the courier but are not guaranteed. Customers can reschedule through the courier's tracking link when the option is available.

## What If the Order Has Already Shipped?
If modification is not possible because the order has shipped, the customer can:
- Refuse delivery or return the item after delivery (see cancellation_policy and return_policy).
- Contact the courier through the tracking page for delivery instructions.
- Ask support to raise an escalation if the delivery address was entered incorrectly because of a site error.

## Modification Confirmation
Every approved modification is confirmed by email and SMS. If no confirmation is received, the change should be considered not applied, and the customer should contact support.
